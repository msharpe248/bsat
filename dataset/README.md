# SAT Solver Test Datasets

This directory contains various SAT instance datasets used for benchmarking and testing.

## Datasets

### Generated Test Suites

These test suites are **generated using scripts** in `../research/benchmarks/`:

#### Medium Tests
- **Generated by**: `../research/benchmarks/generate_medium_tests.py`
- **Size**: 53 instances
- **Difficulty**: 10-120 variables, ranging from easy to moderately hard
- **Purpose**: Primary benchmarking suite showing meaningful performance differences
- **Regenerate**: `cd ../research/benchmarks && ./generate_medium_tests.py`

#### Simple Tests
- **Generated by**: `../research/benchmarks/generate_simple_tests.py`
- **Size**: 9 instances
- **Difficulty**: 5-30 variables, very easy
- **Purpose**: Quick validation that solvers work correctly
- **Regenerate**: `cd ../research/benchmarks && ./generate_simple_tests.py`

### Competition Benchmarks

#### SAT Competition 2025
- **Source**: https://satcompetition.github.io/2025/
- **Details**: See `sat_competition2025/README.md`
- **Status**: Not included. `sat_competition2025/` contains only its README; the instances (399 in the full set, in per-family subdirectories) must be downloaded separately and there is no download script in this repo
- **Difficulty**: Extremely challenging - designed for industrial solvers
- **Warning**: Most instances will timeout on basic implementations

#### SAT Competition 2025 Small Subset
- **Generated by**: `../research/benchmarks/create_small_test_set.py`
- **Source**: Filtered from `sat_competition2025/` (requires the full set to be downloaded first)
- **Status**: Not included. `sat_competition2025_small/` is created by the script and does not exist in a fresh checkout
- **Size**: 8 instances when last generated (≤ 500 variables, ≤ 2000 clauses, ≤ 0.5 MB)
- **Difficulty**: Still very hard, most will timeout
- **Purpose**: Smallest competition instances for testing limits
- **Regenerate**: `cd ../research/benchmarks && ./create_small_test_set.py`

#### On-Demand Corpora (`corpora/`)
- **Fetched by**: `../competition/c/scripts/fetch_corpora.py` (see [below](#download-competition-benchmarks--wide-satlib-suites-on-demand))
- **Location**: `corpora/<pack>/`, each with a `manifest.json`; the whole directory is gitignored
- **Packs**: `synthetic-hard`, `repo-all`, `satlib-core`, `satlib-hard`, `satlib-scale`, `satcomp-2023`, `satcomp-2024`, `satcomp-2025`
- **Purpose**: Wide verification/benchmark runs of the C solver via `../competition/c/scripts/suite_runner.py`

## Notes

- **Simple and medium suite CNF files are checked into git** (9 + 53 files); `.gitignore` excludes all other `dataset/**/*.cnf`, so newly generated or downloaded instances are not picked up automatically
- **Competition instances and `corpora/` are not checked into git** (too large)
- **Named result directories are checked in** (e.g., medium_suite_results_oct_2025)
- **Temporary result directories are gitignored** (results-YYYY-MM-DD-HH-MM-SS pattern)

## Regenerating Datasets

### Generate all test suites:
```bash
cd ../research/benchmarks

# Generate simple tests (9 instances)
./generate_simple_tests.py

# Generate medium tests (53 instances)
./generate_medium_tests.py

# Create small competition subset (needs dataset/sat_competition2025 downloaded first)
./create_small_test_set.py
```

### Download competition benchmarks & wide SATLIB suites (on-demand)
Use the on-demand corpus fetcher and parallel verification runner (stores
downloaded suites in gitignored `dataset/corpora/`). Run from the repository
root; `suite_runner.py` defaults to the C solver binary `competition/c/bin/bsat`
(build it with `make -C competition/c`):

```bash
python3 competition/c/scripts/fetch_corpora.py list
python3 competition/c/scripts/fetch_corpora.py fetch synthetic-hard satlib-core
python3 competition/c/scripts/fetch_corpora.py fetch satcomp-2024 --limit 60 --max-mb 2
python3 competition/c/scripts/suite_runner.py --corpus satlib-core --timeout 10 --workers 4
```

See `sat_competition2025/README.md` for background on the full 54 GB SAT
Competition 2025 archive.

## Running Benchmarks

```bash
cd ../research/benchmarks

# Run on medium tests (recommended)
./run_all_benchmarks.py ../../dataset/medium_tests -t 30

# Run on simple tests (quick validation)
./run_all_benchmarks.py ../../dataset/simple_tests -t 10

# Run on competition benchmarks (only after downloading them; expect timeouts)
./run_all_benchmarks.py ../../dataset/sat_competition2025 -t 120
```

Results are written to `results/results-YYYY-MM-DD-HH-MM-SS/` (gitignored).

The simple and medium suites are also used directly by the C solver's scripts
and tests (`../competition/c/Makefile`, `../competition/c/scripts/`,
`../competition/c/tests/`).

See `../research/benchmarks/README.md` for complete benchmarking documentation.
